# Operator shift checklist

Use this checklist at the start and end of an imaging release shift.

## Start of shift

- confirm the active release window and lane ownership changes
- identify blocked lanes and partner-facing lanes first
- open the latest packet and verify digest, top issue codes, and current brief
- check whether any manifest exception is still valid or expired

## During investigation

- keep machine summaries and human notes aligned
- capture the last accepted packet before re-running anything
- prefer lane-local decisions over broad bundle assumptions
- record which healthy lanes are still safe to move

## End of shift

- leave the lane, digest, issue codes, and safe next action in the first lines of the handoff
- call out partial rollouts explicitly
- note any partner packet that is still blocked even if internal lanes continued
- remove guesses; leave facts and next checks

## Reminder

Leave lane names and issue codes exactly as the packet rendered them. Paraphrasing is where handoffs get fuzzy.
Keep the packet digest near the top of the handoff so anyone opening the note can verify they are reading the same evidence set.
A short, factual note beats a long vague note every time.
Name the next check clearly.
Keep it plain.
Be exact.
Done.
!
